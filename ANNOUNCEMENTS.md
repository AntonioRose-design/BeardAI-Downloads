# BeardAI Official Announcements

## October 23, 2026 — Royal Evolution 3.0.1 is public

The **3.0.1 Royal Evolution Hotfix prerelease** is now available for Android and Windows.

[Read release notes](RELEASE_NOTES_v3.0.1-royal-evolution-hotfix.md) · [Download Android and Windows](https://github.com/AntonioRose-design/BeardAI-Downloads/releases/tag/v3.0.1-royal-evolution-hotfix)

**What's new:** Windows launcher/branding fix with isolated local-server identity, Android version alignment, and in-app Royal Tasks companion reminders. All build/publish jobs completed successfully.

**What is not shipped:** 1,000 implemented additions, unattended Ant Legion gameplay automation, full background tasks, iPhone IPA and TestFlight. The 100-feature engineering roadmap documents intended work rather than delivered features.

## What is being developed next

A **Feedback Center** has been added to development source for user-reviewed GitHub issue submissions and local drafts. It is **not in the public 3.0.1 binaries**. Future work includes accessible navigation, guide interactions, safe export/import, reliable task notifications, an iPhone-compatible build and user-approved automation. Feedback submission cannot continuously send messages to this ChatGPT conversation or automatically approve/deploy code.

[Development source](https://github.com/AntonioRose-design/BeardAI-Android/tree/beardai-2.2-community-media-updates) · [100-feature roadmap](https://github.com/AntonioRose-design/BeardAI-Android/blob/beardai-2.2-community-media-updates/ROADMAP_BEARD_AI_3_0_100_FEATURES.md)
