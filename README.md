### What's actually new

**Royal Workbench 5.0** adds local personal planning records, editing, priorities, stages, optional due dates, notes and completion actions, and JSON backup export/import with merge/replace validation. **Feature Compass** makes the complete **1,000-item roadmap (40 systems)** searchable with clear status labels. The roadmap is an engineering backlog: **those 1,000 proposed items are NOT 1,000 implemented or tested additions**.

The new Windows preview uses local port **18755** and health identity **BEARDAI_LOCAL_V500**, separate from 4.0.1. Android is a debug-signed preview APK. The iPhone edition is a **Safari Home Screen web app** published with GitHub Pages, **not** an App Store/TestFlight native IPA.

### Install on iPhone

Open the [BeardAI website](https://antoniorose-design.github.io/BeardAI-Downloads/) in **Safari**, then tap **Share → Add to Home Screen → Add**. No Apple Developer membership is needed. Safari login, uploads, offline behavior and cross-device compatibility still need physical-device testing; Android screen capture is not available in iOS Safari.

### Updating safely

Extract the Windows ZIP into a **new folder** and run `OPEN_BEARDAI_NOW.bat`. Back up personal Intel and Workbench data first: old Windows browser storage on port 18754 is separate from the 5.0 origin on port 18755. Android installation may require a reinstall if its debug signing key differs.
