# 👑 BeardAI 2.2 — Emoji Community Preview

**Public experimental Android prerelease | v2.2.0-dev | October 23, 2026**

## ✨ What's new
- 😀 **Emoji composer:** add emojis while writing community messages.
- ❤️ 😂 🔥 👑 👍 🐜 **Message reactions:** react to posts in BeardAI's private community rooms. Access is restricted by owner-approved membership policies.
- 🔔 **Update check:** view availability of newer official GitHub releases. This is a notification/link feature, not a silent installer.
- 💬 **Community chat:** General, Strategy, Events and Help rooms, with separate accounts, owner approval and reporting.

The APK is a debug-signed testing build; back up local data before replacing an older installation. Android may require confirmation to install sideloaded APKs. Version/signing differences can require uninstalling a previous build.

## 🧪 Beta test checklist
1. Register or sign in with a separate BeardAI account (never an Ant Legion password).
2. Confirm owner approval, then open General chat.
3. Send an emoji, then react to a message.
4. Check a second approved member sees the new message and reaction.
5. Try Update Check. Report any errors from Android WebView.

## ⚠️ Not in this preview
GIF sending, image/photo uploads, automatic background app installation and verified end-to-end device compatibility. All are still under development. Do not treat the 2.2 preview as a finished media-sharing release.

## 🔐 Privacy and independence
This is an independent community, **not** Ant Legion's built-in chat. Members must be approved. Messages are not end-to-end encrypted; moderators can access content. Avoid posting credentials, private coordinates or sensitive personal information. BeardAI is unaffiliated with Ant Legion, 37GAMES, Google and OpenAI.
